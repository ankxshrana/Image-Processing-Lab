# Image Processing Lab: Fundamentals

## Overview
This repository contains a Jupyter Notebook designed for an introductory Image Processing lab[cite: 1]. The code is built to run in Google Colab and covers the fundamental operations using the OpenCV library[cite: 1]. 

## Lab Contents
* **Step 0: Download Sample Data**: Automates the downloading of a sample image (`lena.jpg`) and a sample video (`car-detection.mp4`) from online GitHub libraries using `urllib`[cite: 1].
* **Part 1: Image Operations**: Demonstrates how to load an image using `cv2.imread()`, display it within the Colab environment using the `cv2_imshow` patch, and save a new copy to the disk using `cv2.imwrite()`[cite: 1].

## Requirements
To run this notebook successfully, you will need:
* A Google Account to access **Google Colab**[cite: 1].
* Basic familiarity with **Python 3**[cite: 1].
* The `cv2` (OpenCV) library, which comes pre-installed in the Colab environment[cite: 1].

## Usage
1. Open the `.ipynb` file in Google Colab[cite: 1].
2. Run the cells sequentially. Ensure you run Step 0 first so the required `sample_image.jpg` is present in your virtual environment before attempting Part 1[cite: 1].
